ABOUT THIS PROJECT
Pulse is a free, open-source dashboard for understanding organizational
performance: active users, uptime, response time, task completion, network
traffic, resource allocation, and team progress. It replaces the original
basic HTML tutorial while preserving the project's 2023 origin.

MAKE IT YOURS
1. Open https://georgiarachel07.github.io/pulse-kpi-dashboard/
2. Select Make it yours.
3. Enter your organization and your name or role.
4. Enter your KPI values and resource allocation percentages.
5. Add or remove teams and enter each team's total and completed tasks.
6. Select Save my workspace. Your values are saved in this browser and
   displayed in manual mode; the simulation will not overwrite them.
7. Select Download my dashboard in the About section to generate a single
   HTML file containing your workspace, styling, and application code.
8. Open your downloaded file, edit it, or publish it on your own static host.
   Charts, icons, and fonts still need an internet connection.

YOUR OWN REPOSITORY
Use the repository's template option or fork the project:
https://github.com/georgiarachel07/pulse-kpi-dashboard
Copy or edit index.html, style.css, and script.js. Follow README.md to publish
your own version through GitHub Pages. Preserve the MIT license notice.

HOW DATA WORKS
The initial demo uses simulated data and refreshes every three seconds while
visible. Personal workspaces show your manually entered figures. Local browser
storage is not a shared team database. Clearing site data removes local saved
settings. Download your dashboard as a backup. A downloaded file includes the
figures you export, so only publish information you intend others to see.
No organization data is sent to an application backend by this project.
